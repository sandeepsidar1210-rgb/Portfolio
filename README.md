# Sandeep Kumar Sidar — Portfolio

Personal portfolio for Sandeep Kumar Sidar, a software engineering student and full-stack developer at IIIT Naya Raipur.

## Highlights

- Full-stack web development with React, Node.js, Express.js, and Django
- Backend architecture with REST APIs, Redis, MongoDB, MySQL, and Supabase
- AI-powered developer tooling with Gemini API integrations
- 250+ competitive programming and DSA problems solved
- Experience across EduLinkUp, WebDev Club, ELUSOC, and SwasthOS

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the portfolio.

## Build

```bash
npm run build
```

## Project structure

- `src/app/page.tsx` — editorial homepage
- `src/app/about/page.tsx` — experience, education, and skills
- `src/app/work/projects` — project case studies
- `src/resources/content.tsx` — profile and portfolio content
- `src/resources/custom.css` — visual design system
