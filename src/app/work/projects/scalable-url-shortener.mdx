## Overview

Scalable URL Shortener is a backend-focused service designed for fast redirect resolution and efficient storage. It combines custom Base62 encoding with Redis caching to keep frequently accessed links away from the primary database.

## Engineering highlights

- Built high-throughput REST endpoints with Node.js and Express.
- Implemented custom Base62 encoding for compact short links.
- Added Redis caching that cut database read loads by 60%+.
- Used MongoDB for durable URL and analytics data.
