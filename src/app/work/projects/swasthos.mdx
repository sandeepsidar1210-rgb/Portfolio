## Overview

SwasthOS is a health technology project focused on making emergency coordination more responsive and secure. As co-founder and a full-stack developer, I worked on the workflows that connect emergency alerts, communication, and access-controlled health data.

## Key Contributions

- Engineered real-time emergency alert workflows and communication pipelines.
- Integrated Twilio APIs with asynchronous webhooks for dependable notifications.
- Applied role-based authorization and data security filters to protect sensitive workflows.
- Resolved CORS configuration issues across client and server boundaries.

## Technologies

React, Node.js, Express.js, MongoDB, Twilio APIs, REST APIs, and asynchronous webhooks.
