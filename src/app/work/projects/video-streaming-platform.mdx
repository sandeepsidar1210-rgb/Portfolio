## Overview

Video Streaming Platform Backend is a media microservice designed around reliable uploads and delivery. It supports chunked streaming pipelines and separates authentication, media processing, and persistence into clear RESTful workflows.

## Engineering highlights

- Architected RESTful APIs for media upload, playback, and management.
- Implemented chunked streaming pipelines for large video assets.
- Connected Multer and Cloudinary for managed media processing and delivery.
- Added JWT and Bcrypt authentication for protected user and media operations.
