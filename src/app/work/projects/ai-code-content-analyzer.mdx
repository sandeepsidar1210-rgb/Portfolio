## Overview

AI Code & Content Analyzer is a full-stack tool built during the EduLinkUp internship to help developers evaluate code and content through a practical analytics workflow. It combines automated checks with AI-assisted feedback and presents results through an interactive dashboard.

## Key Features

- Automated static code linting, vulnerability scanning, and syntax evaluation.
- Gemini API integrations for intelligent code and content analysis.
- Interactive analytics dashboards with charts for communicating scan results.
- MongoDB aggregation pipelines for processing analysis data.
- Export workflows for reports in PDF and image formats.

## Technologies

React, Node.js, Express.js, MongoDB, Gemini API, Recharts, REST APIs, PDF export, and image export.
